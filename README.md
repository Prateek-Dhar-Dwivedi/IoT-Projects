# IoT Projects Portfolio 🚀

A complete, production-ready portfolio of 10 embedded systems and IoT projects built using **Arduino Uno**, **ESP32**, **NodeMCU (ESP8266)**, **Ultrasonic sensors (HC-SR04)**, **IR proximity sensors**, **piezo buzzers**, and **LEDs**.

---

## 📦 Hardware Inventory
- **Microcontrollers:** 1x Arduino Uno R3, 1x ESP32 Dev Module, 2x NodeMCU (ESP8266), 1x ESP-12E
- **Sensors:** 2x Ultrasonic Sensors (HC-SR04), 1x IR Proximity/Obstacle Sensor
- **Actuators & Outputs:** 1x Piezo Buzzer, Multiple LEDs (Green, Red, Yellow), 220Ω Resistors
