# IoT Projects Portfolio 🚀

A complete, production-ready portfolio of 9 embedded systems and IoT projects built using **Arduino Uno R3**, **Dual Ultrasonic sensors (HC-SR04)**, **IR proximity sensor**, **piezo buzzer**, and **LED indicators** — engineered with a **Universal Zero-Rewiring Breadboard Architecture**!

---

## 📦 Hardware Inventory & Universal Breadboard Setup
All 9 projects in this portfolio run on the **exact same hardware wiring**. Once wired, you can upload and demo any of the 9 projects immediately without changing a single jumper wire!

- **Microcontroller:** 1x Arduino Uno R3
- **Sensors:** 
  - 2x HC-SR04 Ultrasonic Distance Sensors
  - 1x Active IR Proximity / Obstacle Sensor
- **Actuators & Outputs:** 
  - 1x Piezo Buzzer (Pin 10)
  - 3x LEDs (Green on Pin 7, Red on Pin 8, Yellow on Pin 9) + 220Ω Resistors
- **Wiring & Power:** 1x Solderless Half/Full Breadboard + Jumper Wires
